# amazon-product-due-diligence

[English](README.md) | 简体中文

一个 AI Skill（附带一个单品利润计算器），在你花钱打样、备货之前，对亚马逊 FBA 候选产品做尽调，最后给出明确结论：**能做 / 再想想 / 别做**。

可以作为 Claude 的 Skill 使用，也可以给任何能读 Markdown 指令文件的 AI 工具用。计算器可以单独运行。

## 它做什么

1. **定义产品**：精确到 listing 级别，并核对竞品是不是真的同一种东西。
2. **红线检查**：价格带、平台、高监管品类（FDA、FCC、儿童产品）、知识产权和授权风险。
3. **四个维度打分**，每项都有明确门槛：
   - **市场需求**：BSR、估算销量、12 个月趋势、退货率
   - **竞争强度**：评论壁垒、头部集中度、价格分布、1–3 星差评里的痛点、差异化空间
   - **单品利润**：佣金、FBA 配送费、采购成本、头程、退货、广告、毛利率、加价倍数、回本销量
   - **执行难度**：起订量、重量与尺寸档、合规、季节性
4. **标出危险信号**：亚马逊自营进场、专利、报价低得可疑、新品扎堆上架。
5. **给结论**：附理由，再给上线注意事项或必须先解决的问题。
6. **最后列数据可信度**：哪些已核实、哪些是估算、哪些拿不到，以及要花多少钱才能拿到。

## 最重要的两条原则

- **客观中立。** 好产品就说能做，坏产品就说别做，不为显得专业硬挑毛病，也不为照顾情绪假装乐观。
- **不编数字。** 每个数字都标明 `[已核实 — 来源 @ 日期]`、`[估算 ±N% — 依据]` 或 `[拿不到 — 怎么获取]`。平台费用一律以亚马逊当前费率表为准，不凭记忆报数。

## 计算器

```bash
python3 skills/amazon-product-due-diligence/scripts/unit_economics.py \
  --price 45 --cogs 8 --fba 9.5 --referral-pct 15 \
  --freight 3 --packaging 1 --return-pct 5 --acos 25 --budget 3000
```

输出单品利润表、毛利率、加价倍数（售价 ÷ 采购成本）和回本销量，并按 Skill 的门槛给出评级。加 `--json` 可输出 JSON。

## 可以调整的默认设置

红线默认按「小批量测款」的思路设定：**价格 $15–100、首批约 $3,000、亚马逊美国站**。按你的策略修改 `SKILL.md` 第 1 节（以及计算器的 `--budget`）即可。

精简版示例见[示例报告](examples/sample-report.md)。

## 安装

**Claude：** 把 `skills/amazon-product-due-diligence/` 复制到 `~/.claude/skills/`（或项目里的 `.claude/skills/`），然后附上竞品链接和工厂报价：

> 这个产品能在亚马逊上做吗？目标售价 $45，这是 3 个竞品和 2 家工厂报价。

**其他 AI 工具：** 把 `SKILL.md` 作为指令文件。

## 文件结构

```
skills/amazon-product-due-diligence/
├── SKILL.md                   # 原则、红线、9 节报告、结论规则
└── scripts/
    └── unit_economics.py      # 单品利润、加价倍数、回本销量
examples/
└── sample-report.md           # 精简示例（数字仅作演示）
```

本工具不构成投资或财务建议，只是帮你更有依据地做决定。
